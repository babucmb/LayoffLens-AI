## Title

## Tagline

## Short description
WRI links synthetic finance, project, capacity, hiring, AI-investment, and infrastructure signals into an evidence-grounded investigation workflow. Deterministic calculations expose aggregate mismatches, bounded agents gather evidence, and Meta model synthesis explains options for human review. It does not score employees or automate employment decisions.

## Meta usage
The single `MetaModelClient` routes the executive brief to a documented Meta Model API model in live mode. The default demo mode is an honest deterministic fallback and is labeled in the UI.
