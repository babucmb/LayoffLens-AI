# Data model

The demo contains finance periods, projects, aggregate capacity by skill and unit, hiring commitments, AI investment metrics, simulated external signals, scenario assumptions, agent runs, and review records. IDs such as `project:P-104` provide local lineage and citation.

No named employees, payroll, personal data, customer contracts, or real company claims are included. In production, retain source identity, schema version, timestamp, consent/authorization, lineage, and retention policy for every record.
