# Known limitations

- Default agent execution is deterministic simulation, not live autonomous
  model reasoning.
- The local work record is not a distributed queue.
- No live external research provider is configured.
- The Meta live path has not been credential-verified.
- Data is synthetic and aggregate-only.
- Authentication and audit controls are local reference controls, not SSO,
  encryption-at-rest, immutable audit, or compliance certification.
- Numerical calculations remain deterministic application code by design.
- Human review is required; the system does not execute business or employment
  interventions.
