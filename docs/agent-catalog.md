# Agent catalog

| Agent | Input | Approved work | Output |
|---|---|---|---|
| Orchestrator | event and risk IDs | route fixed steps | run plan |
| Finance | finance records | variance arithmetic | evidence summary |
| Project demand | project pipeline | weighted demand | project evidence |
| Workforce capacity | aggregate capacity | demand minus capacity | skill gaps |
| AI investment | adoption and spend | compare signals | investment evidence |
| Forecast | validated metrics | scenario formulas | projections |
| Evidence/policy | all structured outputs | freshness, citations, aggregate-only check | policy result |
| Executive briefing | validated outputs | Meta synthesis or template | cited brief |

Every step is bounded and auditable. Demo mode uses deterministic application functions; live Meta inference is only used for language synthesis.
